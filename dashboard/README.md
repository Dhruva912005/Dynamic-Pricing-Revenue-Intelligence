# Dynamic Pricing & Revenue Intelligence — Power BI Suite

This directory contains the business intelligence assets for the Dynamic Pricing project:

1. **`Dynamic_Pricing_Data_Enriched.csv`**: Master consolidated dataset containing historical sales, competitor pricing, demand forecasts, and optimized price recommendations.
2. **`PowerBI_Dashboard_Specification.md`**: Complete enterprise dashboard specification with all 6 report pages, visual layouts, themes, conditional formatting rules, and DAX measures.
3. **`generate_pbix_template.py`**: Python script to verify and regenerate Power BI datasets.

### Quick Start:
To load the dashboard into Power BI Desktop:
1. Open Power BI Desktop.
2. Load `Dynamic_Pricing_Data_Enriched.csv`.
3. Follow the measures and page templates in `PowerBI_Dashboard_Specification.md`.
